# UXQ 评价维度

UXQ 使用 6 个评价维度（D01-D06）覆盖 UX 评价的核心方面。纯静态采集（无交互动作）时 D02/D05/D06 为 OOS（不适用）。

## 维度定义

| ID | 名称 | 说明 | 静态采集 |
|---|---|---|---|
| D01 | 任务有效性 | 用户能否完成目标任务 | 可测 |
| D02 | 操作效率 | 完成任务所需的时间和步骤 | OOS |
| D03 | 可理解性与认知支持 | 界面信息是否清晰易懂 | 可测 |
| D04 | 可访问性与包容性 | 是否满足不同能力用户的需求 | 可测 |
| D05 | 交互可靠性与错误恢复 | 系统稳定性和错误处理能力 | OOS |
| D06 | 主观体验 | 用户满意度和情感反应 | OOS |

## OOS（Out of Scope）说明

当维度标记为 OOS 时：
- 该维度不参与评分计算
- 报告中必须显式声明该维度未覆盖
- 不能对该维度做出任何结论

## 使用场景

在评价定义文件的 `dimensions` 字段指定要评价的维度：

```json
{
  "dimensions": ["D01", "D03", "D04"]
}
```

建议至少包含 D01（任务有效性）和 D03（可理解性）。
