# 认知负荷：能力与证据边界

当前 CLI 没有 cognition 子命令，不会访问 URL 后自动生成 NASA-TLX。@uxq/cognition 提供独立领域计算，需要调用方提供符合 API 的数据并自行接入采集链路；SDK 存在不代表 CLI 已自动执行。

先区分任务复杂度代理数据、专家判断和实际用户主观负荷。NASA-TLX 需要真实参与者回答及研究方法记录；按钮数量、页面截图或机器操作时长不能替代问卷。

如已有合法量化输入，可显式声明离线观测、指标、策略与来源限制，再使用通用 validate/plan/evaluate 流程。研究证据同意书不能由 observation 自动补造。无法获得数据时给出待采集清单，不给主观负荷分数。

报告使用 D03 可理解性与认知支持；NASA-TLX 的六个分量不是 UXQ 的 D01–D06。
